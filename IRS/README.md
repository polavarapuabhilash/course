# Information Retrieval Systems (IRS) Lab

This repository contains Information Retrieval Systems (IRS) laboratory programs implemented using Python and Jupyter Notebook.

## 📂 Files

### 1. `irslab1.ipynb` — TF-IDF and Cosine Similarity

This program demonstrates document representation using **TF-IDF (Term Frequency–Inverse Document Frequency)** and measures the similarity between two documents using **Cosine Similarity**.

**Topics Covered:**

* TF-IDF Vectorization
* Text preprocessing
* Stop word removal
* Cosine Similarity

**Libraries Used:**

* Scikit-learn

---

### 2. `Irslab2.ipynb` — Stop Word Removal and Stemming

This program performs basic text preprocessing using the **Natural Language Toolkit (NLTK)**.

**Operations Performed:**

* Tokenization
* Stop word removal
* Filtering non-alphabetic words
* Stemming using Porter Stemmer

**Libraries Used:**

* NLTK

---

### 3. `Irslab3.ipynb` — Inverted Index Construction

This program constructs an **Inverted Index** from text documents.

The program:

* Reads `.txt` documents from a folder
* Converts text to lowercase
* Removes special characters
* Creates a vocabulary
* Builds an inverted index mapping terms to documents
* Processes user search queries
* Displays the documents containing the searched term

**Concepts Covered:**

* Text preprocessing
* Document indexing
* Vocabulary construction
* Inverted Index
* Query processing
* Document frequency

---

## 🎯 Learning Objectives

* Understand text preprocessing techniques
* Learn TF-IDF representation of documents
* Calculate document similarity using Cosine Similarity
* Perform stop word removal and stemming
* Construct and use an Inverted Index
* Understand basic query processing in Information Retrieval Systems
